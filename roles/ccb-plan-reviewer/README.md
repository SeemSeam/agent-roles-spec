# CCB Plan Reviewer

`ccb-plan-reviewer` is an experimental Role for independent review of CCB
planner artifacts.

The reviewer approves readiness only when scope, acceptance, verification, and
risk handling are concrete. It returns a review artifact; scripts or later
workflow roles decide authoritative state.

The canonical Role id is `agentroles.ccb_plan_reviewer`. Suggested aliases are
`ccb-plan-reviewer`, `ccb_plan_reviewer`, and `plan-reviewer`.
