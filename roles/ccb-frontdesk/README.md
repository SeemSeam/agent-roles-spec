# CCB Frontdesk

`ccb-frontdesk` is an experimental Role for the CCB user-facing workflow
boundary.

Frontdesk is intentionally not the strongest or deepest role. It keeps user
conversation clean, delegates planning and execution, and presents curated
questions or final summaries.

The canonical Role id is `agentroles.ccb_frontdesk`. Suggested aliases are
`ccb-frontdesk`, `ccb_frontdesk`, and `frontdesk`.
