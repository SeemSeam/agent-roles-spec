# Demo Catalog Reference

Use this reference to keep frontend examples useful without copying external
source.

## Entry Shape

```md
## Source Name

- URL:
- Authority: official / maintained / community / unknown
- License posture:
- Tags:
- Use for:
- Do not use for:
- Access date:
```

## Curation Rules

- Prefer project-local examples and official docs.
- Use Storybook Showcase and maintained component docs as link-only
  inspiration.
- Keep at most one project-local example, one official/design-system example,
  and one external inspiration reference per product surface.
- Translate examples into original constraints: hierarchy, density, state
  design, component composition, motion, and validation checks.
- Reject copying protected, private, or license-unclear designs or code.

## Tags

- surface: dashboard, editor, commerce, docs, analytics, workflow, developer
  tool, AI app;
- density: operational, editorial, immersive, compact, mobile-first;
- component: navigation, form, table, chart, command palette, modal, settings,
  empty state, onboarding, editor, canvas;
- validation: visual polish, accessibility, performance, interaction, content
  hierarchy, motion, browser compatibility.
