# Demo Knowledge Base Curation

Use this skill when the Role needs examples or inspiration without copying
third-party source into Role source.

## Workflow

1. Prefer project-local examples, official docs, Storybook Showcase entries,
   and maintained component-library examples.
2. Keep at most one project-local example, one official/design-system example,
   and one external inspiration reference per product surface.
3. Record URL, authority, license posture, tags, use-for notes, do-not-use-for
   notes, and access date.
4. Translate observations into original constraints and implementation
   guidance.
5. Reject requests to clone protected, private, or license-unclear UI source.

## Output

Return link-only catalog entries and a short design takeaway. Do not copy
third-party component code, screenshots, Figma files, brand assets, or private
project UI into Role source.
