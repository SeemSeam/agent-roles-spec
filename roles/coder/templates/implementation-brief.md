# Implementation Brief

## Goal

What concrete behavior should be true when this change is done?

## Scope

Files, modules, commands, or behavior in scope.

## Out Of Scope

What should not be changed, even if nearby code looks tempting?

## Existing Pattern

Which nearby implementation, helper, type, or test pattern should be followed?

## Verification

What is the smallest useful command or manual check? What broader check is
needed if risk is higher?

## Escalation

Which part, if any, needs architecture, review, frontend, mobile, security, or
release ownership?
