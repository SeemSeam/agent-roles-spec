# Dependency Change Gate

Use before adding, upgrading, removing, or locking dependencies.

## Need

What current task requires this dependency change?

## Existing Alternative

Which existing project dependency, helper, platform API, or small local
implementation was considered first?

## Scope

Runtime dependency, dev dependency, transitive lockfile update, or tooling
change?

## Risk

Bundle size, license, maintenance, security, platform support, and compatibility
impact.

## Approval

Who approved the dependency change?

## Verification

Commands run after the dependency change.
